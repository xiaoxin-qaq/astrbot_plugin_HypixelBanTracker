# Hypixel 封禁统计插件 更新日志

## v2.1.1 — 2026-09-06

### ✨ 新增特性
- **真正随机背景图**  
  插件启动时预加载全部 5 张背景图并缓存为 Base64，每次生成图片时随机选取一张，彻底解决背景图“永远只显示一张”的问题，视觉体验更丰富。

- **用户交互提示**  
  执行 `/hacker` 命令后，机器人会立即 @ 发送者并显示“正在查询封禁统计信息，请稍候..”，提升操作反馈感，避免用户等待时的茫然。

### 🔧 变更与优化
- **移除虚假系统事件**  
  最近活动列表中删除了“封禁统计接口已同步最新快照”的模拟条目，所有活动均基于真实的 `lastMinute` 数据（若为 0 则不显示），或合理的 Watchdog / Staff 历史模拟记录，数据展示更真实可信。

- **界面更通透（液体玻璃效果）**  
  - 背景黑色遮罩透明度从 `0.55` 降低至 `0.25`  
  - 卡片背景不透明度从 `0.78` 调整至 `0.6`  
  - 毛玻璃模糊强度从 `16px` 提升至 `12px`（视觉上更柔和）  
  以上调整使背景图片更清晰可见，整体观感更加轻盈现代。

### 🛠 技术调整
- **背景图预加载机制**  
  新增 `_preload_bg_images()` 异步方法，在插件初始化时并行下载所有背景图并缓存，避免每次请求重复拉取，显著提升响应速度。

- **随机选择逻辑**  
  实现 `_get_random_bg()` 从缓存列表中随机选取一张 Base64 图片，确保每次渲染的背景不同。

- **代码清理**  
  移除旧的单张缓存变量，替换为列表缓存；移除不再使用的 `sys` 类型活动生成逻辑。

## v2.0.0 — 2026-09-05

### ✨ 新增特性
- **可视化图片渲染**  
  不再仅返回纯文本，现在通过 HTML 模板动态生成精美的封禁统计图片，直接发送到聊天窗口。

- **毛玻璃卡片设计**  
  Watchdog 与 Staff 数据分别以独立卡片展示，包含今日累计、历史总计、过去 1 分钟三个关键指标，信息一目了然。

- **随机背景图**  
  内置 5 张精选背景，每次请求随机切换（v2.1.0 之前仅缓存单张，现已修复为真正随机）。

- **最近活动列表**  
  显示当前分钟内的真实封禁快照，并辅以历史模拟事件（如“Watchdog 自动封禁 X 个玩家”），让数据更具叙事性。

- **自动降级机制**  
  若图片渲染失败（如环境缺失），自动回退为纯文本格式输出，确保核心数据始终可达。

- **数据格式化**  
  所有大数字自动添加千位分隔符，提升可读性。

### 🔧 变更与优化
- **移除在线人数显示**  
  根据用户反馈，删除了顶部在线人数区域，界面更聚焦于封禁核心数据。

- **移除 ECharts 曲线图**  
  简化布局，将原图表面板替换为全宽的“最近活动”面板，避免视觉冗余。

- **增强背景可读性**  
  在背景图上叠加半透明黑色遮罩（rgba(0,0,0,0.55)），同时提高卡片背景不透明度，确保所有文字清晰可辨。

- **强化文字阴影**  
  为标题、数值、标签等增加更深层的阴影，适应暗色背景。

### 🛠 技术调整
- 重构 `render_image` 方法，移除不再使用的 `player_count` 相关请求与变量。
- 清理无用代码（曲线图数据生成、速率计算等），提升插件执行效率。
